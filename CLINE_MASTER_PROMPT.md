# MASTER PROMPT CLINE — ADAUNDANGAN

Bangun aplikasi **AdaUndangan** dari awal sampai siap deploy di repository ini.

Anda bertindak sebagai Senior Full-Stack Engineer, UI/UX Designer, QA Engineer, Security Engineer, dan DevOps Engineer.

## Wajib dilakukan

1. Baca `.clinerules`.
2. Baca `PROJECT_CONTEXT.md`.
3. Baca semua file `docs/`.
4. Periksa workspace.
5. Jangan membuat project nested.
6. Inisialisasi Next.js App Router di root repository.
7. Gunakan TypeScript strict, Tailwind CSS, React Hook Form, Zod, Google APIs, Sonner, Vitest.
8. Buat aplikasi lengkap sesuai `docs/FEATURE_AUDIT.md` dan `docs/OPERATIONAL_SOP.md`.
9. Perbarui `TASKS.md`.
10. Jalankan lint, typecheck, test, dan build.

## Fitur wajib

- Landing page bisnis.
- Dynamic route `/[slug]`.
- Data undangan dari `src/data/invitations/`.
- Nama tamu personal via `?to=`.
- Cover pembuka.
- Musik setelah klik “Buka Undangan”.
- Profil mempelai.
- Detail acara.
- Countdown.
- Kisah cinta.
- Galeri dan lightbox.
- Google Maps.
- Google Calendar URL.
- `/api/calendar/[slug]` untuk ICS.
- Amplop digital opsional.
- RSVP.
- Guestbook approved-only.
- Google Sheets API server-side.
- Demo mode tanpa credential.
- SEO metadata, sitemap, robots.
- README aplikasi.
