# Product Requirements — AdaUndangan

## Pengguna
1. Pemilik usaha.
2. Pasangan calon pengantin.
3. Tamu undangan.

## Kebutuhan pemilik usaha
- Menambah undangan dengan menyalin satu file konfigurasi.
- Mengganti nama, acara, foto, musik, lokasi, tema, dan rekening.
- Melihat RSVP di Google Spreadsheet.
- Menyetujui ucapan melalui kolom `Approved`.
- Mengelola banyak undangan dalam satu repository dan deployment.

## Kebutuhan tamu
- Membuka undangan melalui smartphone.
- Melihat nama personal.
- Mendengarkan musik setelah membuka undangan.
- Melihat acara, lokasi, galeri, dan profil pasangan.
- Menambahkan acara ke kalender.
- Mengisi RSVP dan ucapan.

## Fitur wajib
Landing page, dynamic route, nama tamu, cover, audio, countdown, Maps, Google Calendar, ICS, RSVP, guestbook, Google Sheets, demo mode, SEO, responsive design, accessibility, dan Vercel deployment.

## Batasan
- Tanpa CMS dan database tambahan.
- Bukan static export.
- Secret tidak boleh berada di browser.
- Autoplay hanya dicoba setelah interaksi pengguna.
