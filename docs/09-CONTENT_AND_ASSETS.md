# Content and Assets

## Logo
`public/brand/logo.png`; selalu sediakan fallback text logo.

## Foto
Gunakan WebP/AVIF, kompres, alt text, dan struktur `public/images/invitations/[slug]/`.

Rekomendasi: hero 1600–1920 px, galeri 1000–1400 px, profil 600–900 px.

## Musik
Simpan di `public/audio/`, gunakan file berizin, dan jangan preload penuh.

## Data demo
Harus fiktif. Jangan gunakan rekening nyata, alamat pribadi, nomor telepon pribadi, foto tanpa izin, atau musik ilegal.
